inbox-agent privacy policy

Last updated: October 9, 2026

inbox-agent is a private tool used only by its owner, Moghira Saif, on the owner's own Gmail account. No other users can sign in.

What data it accesses

With the owner's permission (Google scope gmail.modify), it reads recent email threads, creates drafts, sends replies from the owner's account, and adds labels. It cannot permanently delete email.

How the data is used

Email content is sent to Anthropic's Claude API only to classify each email and write a reply. Short summaries of urgent emails are sent to the owner's own phone as notifications. Data is not sold, shared for advertising, or used for any other purpose.

Storage

Sign-in tokens, settings and a log of decisions are stored on the owner's private home server. Nothing is stored on this website.

Google API Services

inbox-agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
